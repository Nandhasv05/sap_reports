# SAP Reports

PHP MVC module for SAP sales reports. Opened from the EVOL portal **SAP Reports** card.

## Layout

```
sap_reports/
  app/          controllers, models, views, core
  config/       app + SAP OData settings
  deploy/       nginx snippets
  public/       css, js, assets, front controller
  routes/       web.php
  storage/      cache
  index.php     front controller
```

## URLs

- Local: http://localhost:8888/sap_reports/
- Dev: http://10.103.10.33/sap_reports/
